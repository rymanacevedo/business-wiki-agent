# PROTOTYPE: wiki schema (throwaway)

> **Status**: reviewed and resolved on 2026-10-18; see the resolution on the ticket. The
> `wiki/` directory reflects the chosen conventions.

This directory is a **prototype**, not production. It answers one question from the
wayfinder ticket [Prototype: wiki schema with a handful of seed documents](https://github.com/rymanacevedo/business-wiki-agent/issues/10):

> How should the wiki look?

It is a hand-built Wiki for the default Bible instance (Northwind Repair LLC, Owner Sam
Rivera, Demo Date 2026-10-17) after Clerk has Ingested five Sources, run one Query, and
run one Lint. Nothing here was generated by an agent; every Page is what we *want*
Clerk to produce, written by hand so the conventions can be judged before they are specified.

## How to read it

There is nothing to run. Read it the way Clerk would:

1. [`wiki/SCHEMA.md`](wiki/SCHEMA.md): the conventions. This is the artifact under review.
2. [`wiki/index.md`](wiki/index.md): the Index, then follow links into Pages.
3. [`wiki/log.md`](wiki/log.md): the Log after the five Ingests, one Query, one Lint.
4. [`wiki/profile.md`](wiki/profile.md): the Profile, carrying the suite-number Contradiction.
5. [`sources/`](sources/): the five raw Sources the Pages cite, so each `(src: …)` can be checked.

Then read [`VARIANTS.md`](VARIANTS.md): the seven conventions where a reasonable
alternative exists, with the alternative shown, so the Owner can pick.

## What the seed exercises

| Source | Shows |
|---|---|
| EIN letter | formation facts into the Profile, a MILESTONE, a non-Obligation (undated filing) |
| Commercial lease | entity Page (landlord), a one-off `lease-notice` Obligation outside the 30-day window |
| City operating permit | a `permit-expiry` Obligation that Lint reports **missed**; the stated fee makes it an Expense Record too |
| Insurance certificate | an `insurance-renewal` Obligation **due within 30 days**; the Suite 210/201 **Contradiction** with the lease |
| Parts invoice | an **Expense Record** with Allocation and `payment: unknown`, a payment-deadline Obligation, a vendor entity, the `supplies` ledger, **Masking** of ACH numbers |

Not shown: Supersession, Suspicious Content, duplicate, `personal`. The Schema describes
each; the eval-design ticket turns them into cases.

## Assumption

The prototype skill offers a logic branch and a UI branch; this question fits neither
exactly. The artifact under review is Markdown, so the "variations" live in
`VARIANTS.md` as side-by-side excerpts rather than as switchable routes.
